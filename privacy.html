应用说明隐私政策使用条款

隐私政策

更新日期：2026-10-08。

访问的数据与用途

在应用所有者授权和指令范围内，应用通过 Google Drive 和 Google Docs API 访问文档名称、文件标识、文件夹关系、修改信息和文档正文，用于文档查找、阅读、摘要与所有者要求的文档编辑。

应用请求 Drive 和 Docs 权限，以访问所有者已有的个人知识库及处理指定文档。权限覆盖范围与每次任务允许操作的范围不同；应用操作应遵守所有者在任务中规定的边界。

处理与存储

Google OAuth 凭据用于连接 Google API，保存在应用服务器的专用私有目录；该说明网站不接收或存储 OAuth 凭据、授权码或个人知识库文档。

文档处理发生在所有者控制的 Agent 环境。执行任务时，选定的文档正文及结果可能进入 Agent 的任务上下文与会话记录。所有者请求 AI 辅助阅读或生成内容时，相关正文可能发送至其配置的模型服务，以完成该项请求；模型服务的处理与保留方式取决于所选服务及配置。

应用不出售 Google 用户数据，不将其用于广告，也不使用这些数据训练自己的通用模型。Google 用户数据仅用于所有者要求的文档功能。数据处理须遵守 Google API Services User Data Policy 及其 Limited Use 要求。

停止访问与删除

所有者可在 Google 账号的第三方连接设置中撤销本应用访问权限，停止后续 Google API 访问。撤销授权不会自动删除原有 Google Drive 文件或 Agent 已保存的会话记录；如需清理服务器凭据或会话资料，应由所有者另行指示。

说明网站

该说明网站不设置文档上传表单，不运行访问分析脚本，也不主动收集 Google 文档内容。拟使用 GitHub Pages 托管。GitHub 会为安全目的记录网站访客 IP 地址；详情见 GitHub Pages 说明 。
